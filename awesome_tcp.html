一条连接，从 TCP 到 WebSocket

TCP 建连后，可选的 TLS 为同一连接加密。先发送普通 HTTP 请求，再用 HTTP Upgrade 切换到 WebSocket，最后收发文本帧。

  1. 1. TCP 建连建立底层连接
  2. 2. 可选 TLS使用上方 TLS 设置
  3. 3. HTTP 请求在连接上发送 GET
  4. 4. HTTP 升级等待 101 响应
  5. 5. WebSocket发送文本帧并接收回显

点击「运行完整演示」，按顺序查看每一步的实际结果。打开 TLS 后可以再运行一次，对比握手结果。
